# Payslip Explanation

Explain this payslip in plain language.

## Structure

1. Summary: "You earned ₱X for this period"
2. Gross Pay (basic + overtime + incentives)
3. Deductions (top 2-3 with amounts)
4. Take-Home Pay (bold)
5. Anomalies vs. last period (>15% variance)

Keep under 250 words. Be empathetic.
